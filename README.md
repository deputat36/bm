# Новостройки Борисоглебска

Независимый городской портал-каталог новостроек Борисоглебска. Проект не является официальным сайтом застройщика, жилого комплекса или отдела продаж.

Основной домен: `https://novostroyki-borisoglebsk.ru/`.

## Архитектура

- статический frontend;
- три приоритетных объекта: Просторная 4А, Аэродромная 18Г и Сенная 76;
- 14 активных форм на семи страницах;
- единственный обязательный маршрут заявки: `assets/js/main.js` → Supabase Edge Function `newbuild-lead` → `public.newbuild_leads`;
- журнал событий: `public.newbuild_lead_events`;
- server-side rate limit и валидация;
- fail-closed формы при отказе основного JavaScript;
- `dry-run` и локальный analytics debug без внешней доставки;
- безопасная тестовая эмуляция отказа localStorage/sessionStorage только в подтверждённом dry-run/debug;
- ежедневный live smoke-test обработчика и автоматическая GitHub-тревога.

Прямая браузерная отправка через Web3Forms не является действующим транспортом и не должна возвращаться.

## Маршрут заявки

1. Браузер валидирует обязательные поля и телефон.
2. В обычном режиме форма обращается только к `newbuild-lead`.
3. Успехом считается подтверждённая сервером запись.
4. В `dry-run` внешняя доставка отключена, создаётся только обезличенное локальное evidence.
5. Если основной маршрут недоступен, форма не должна сообщать об успешной заявке и не должна использовать обходной транспорт.
6. Отказ localStorage или sessionStorage не должен блокировать форму, создавать PII-черновик или запускать альтернативную доставку.

## Проверки

```bash
npm run validate:json
npm run validate:form-qa-results
npm run validate
npm run validate:launch-readiness
```

Фактический QA-реестр содержит 42 статуса. Историческая приёмка на commit `8b9845d` зафиксировала `0 passed / 14 failed / 28 blocked`. Эти evidence не переписываются задним числом.

PR #153 слит в `main` коммитом `6fa7c1e8`: исправлены `placement`, целевой `lead_form_view`, fail-safe storage и state-locked launch-readiness. Автоматические проверки проходят на честной исторической матрице. Issue #151 остаётся открытым до повторного browser QA после исправлений.

## Ограничения публикации

- сохранять `noindex` до прохождения source, legal и launch gates;
- не публиковать неподтверждённые цены, наличие, продавца, договорную схему, ипотечную доступность и ввод секций;
- не использовать закрытые шахматки как публичный источник;

- реальную контрольную заявку выполнять только по отдельному согласию с разрешённым контактом.
