Проверить дополнительный secondary housing-stock discovery по построенным многоквартирным домам Борисоглебска примерно с 2018 года и не создавать дубли уже известных ЖК.

## Решение

Не создавать отдельный reference project `Восточный, 1`.

Наблюдение сопоставляется с уже существующим:

```text
registry=reference
project_id=evropeyskiy-proekt-invest
```

Причина: discovery-источники позволяют идентифицировать адрес как часть уже известного ЖК, а создание отдельной карточки дублировало бы один комплекс в городском каталоге.

## Что не повышается

Точные адреса очередей ЖК «Европейский» не переносятся в buyer-facing reference card только на основании secondary marketplace / housing-stock evidence.

Сохраняются ограничения:

- не утверждать точный состав всех очередей комплекса;
- не утверждать завершённость всего проекта по одному сданному корпусу;
- не переносить текущие цены, наличие и ипотечные условия;
- не считать secondary housing-stock index полным перечнем домов Борисоглебска;
- не переводить `research_queue_complete` в `true`.

## Следующий уровень evidence

Для повышения адресов отдельных очередей в публичной карточке нужен первичный address-level источник: разрешение на строительство/ввод, карточка ЕИСЖС, проектная декларация либо официальный документ застройщика/органа власти с точной объектной привязкой.
