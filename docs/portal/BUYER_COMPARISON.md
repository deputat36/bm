# Сравнение домов и передача выбора — 19.10.2026

Посетитель выбирает два или три дома в городском обзоре и видит таблицу: адрес, застройщик, срок/готовность, этажность, отделка, отопление, источники и даты. Таблица использует принятые publication-allowed confirmed/verified claims и public-ready reference записи. Неизвестные значения не заполняются предположениями. Статус всего проекта не подменяет готовность отдельной секции.

Кнопка заявки добавляет выбранные названия в комментарий существующей подробной формы каталога. Это общий подбор, поэтому single-reference поля удаляются через существующее change-событие выбора «Общий подбор новостройки». Контакты, комнатность, бюджет и способ покупки не перезаписываются. Собственный предыдущий неизменённый блок заменяется; ручной текст не удаляется. Самостоятельно изменённый пользователем блок также сохраняется. Учитывается действующий browser privacy limit comment=1000 (он строже server cap 1500): если объединённый текст длиннее, перенос отменяется с понятным сообщением, без обрезки текста или смены объекта.
