# Reference candidate registry

Дата фиксации: 2026-08-09

## Зачем нужен отдельный реестр

`data/research/reference-projects.json` — только публичный registry подтверждённых справочных объектов.

`data/research/reference-candidates.json` — исследовательская очередь конкретных адресов, которые уже нашли в источниках, но пока нельзя безопасно публиковать либо которые уже прошли отдельный promotion.

Разделение не позволяет вторичной или исторической зацепке случайно стать публичной карточкой.

## Статусы

### `needs_primary`

Есть содержательная зацепка, но нет точного первичного источника, достаточного для идентификации и статуса многоквартирного дома.

### `identity_conflict`

Источники дают конфликтующий контекст по адресу, назначению, объекту или идентичности. До снятия конфликта первичным документом публикация запрещена.

### `promoted`

Кандидат отдельно принят в `reference-projects.json`. Сам candidate registry всё равно не используется frontend-кодом.

## Promotion rule

Кандидат не может рендериться напрямую.

Для unresolved-кандидата обязательны:

- `public_registry_id=null`;
- хотя бы один `acceptance_gap`;
- явный `do_not_render`;
- источники с ограниченным описанием того, что именно они поддерживают;
- repository evidence.

Для `promoted`:

- соответствующая публичная карточка уже должна существовать в `reference-projects.json`;
- `public_registry_id` должен на неё ссылаться;
- исследовательские acceptance gaps должны быть закрыты;
- ограничения на отдельные неподтверждённые характеристики могут сохраняться в `publication_limits`.

## Важная граница

`promoted` означает только, что минимальная reference-карточка прошла свой publication threshold. Это не означает, что разрешено публиковать любые характеристики, текущие цены, наличие, ипотечные условия или создавать отдельную продающую форму.

## Автоматическая защита

`npm run validate:reference` проверяет одновременно:

- публичный registry;
- candidate registry;
- отсутствие unresolved candidate ID в публичном registry;
- наличие promoted target;
- evidence paths;
- отсутствие public-ready полей в candidate registry;
- отсутствие загрузки `reference-candidates.json` из `catalog/index.html` и `assets/js/reference-catalog.js`.

Так исследование может расширяться независимо от публичной выдачи, сохраняя fail-closed публикацию.
