# Безопасный offer feed

Дата: 2026-08-09

Статус: контракт и внутренний preview. Live-источник не подключён, публичный renderer отключён.

## Зачем нужен feed

Портал должен уметь принимать актуальные предложения из управляемого источника без ручного редактирования HTML и без публикации рабочей шахматки как публичного API.

Текущий этап сознательно не содержит реальных квартир, цен, продавцов или внутренних ссылок на таблицы.

## Источник правды

- `data/offers/contract.json` — правила схемы, freshness и публикации;
- `data/offers/feed.json` — нормализованный контейнер; сейчас пуст;
- `tools/validate-offer-feed.mjs` — fail-closed проверка;
- `tools/build-offer-feed-preview.mjs` — внутренний отчёт, не публичная витрина.

Рабочая Google Sheet или backend в будущем должны подключаться через контролируемый импорт. Браузер не должен обращаться к рабочей таблице напрямую.

## Нормализованная строка

Обязательные поля:

```text
object_id
section_or_entrance
apartment_number_public
rooms
area_m2
floor
price
price_checked_at
availability_status
availability_checked_at
seller_type
contract_type
mortgage_status
source_id
publication_allowed
```

`rooms=0` зарезервировано для студии.

## Freshness policy

Без отдельного решения используется консервативный технический порог:

- цена — не старше 24 часов;
- наличие — не старше 12 часов.

Порог является частью технического fail-closed контракта и может быть изменён отдельным проверяемым PR. Отсутствующая дата всегда блокирует публичную строку.

## Publication gates

Даже `publication_allowed=true` в строке недостаточно для появления квартиры на сайте.

Для будущей публичной выдачи одновременно требуются:

1. зарегистрированный `object_id`;
2. `is_public_ready=true` у объекта;
3. принятый управляемый источник feed;
4. подтверждённое основание продавца в метаданных источника;
5. известный тип продавца;
6. известный тип договора;
7. статус `available`;
8. положительная цена;
9. свежая дата цены;
10. свежая дата наличия;
11. глобальный `public_render_enabled=true` отдельным release-изменением.

На 2026-08-09 глобальный renderer отключён.

## Что запрещено хранить в строке

Контракт запрещает персональные и секретные поля, включая имя, телефон и email продавца/клиента, user agent, API key, access token, raw URL рабочей таблицы и внутренние комментарии.

Если в будущем для источника понадобится приватная ссылка или credential, репозиторий должен хранить только `secure:` reference, а не само значение.

## Внутренний preview

Команда:

```bash
node tools/build-offer-feed-preview.mjs
node tools/build-offer-feed-preview.mjs --format=json
```

Preview предназначен для контроля импорта, свежести и статусов. Он не является доказательством текущего предложения и не должен публиковаться как страница портала.

## История цены

Текущий feed хранит только последнее нормализованное состояние. История цены и статусов должна храниться отдельно; текущий контейнер не заменяет журнал изменений.
